# Яндекс Игра — заготовка шаблона _Template10

Яндекс Игры устроены иначе, чем Telegram Mini App (`_TemplateWeb/wwwroot/tma`):

| | Telegram Mini App | Яндекс Игры |
|---|---|---|
| Где живёт игра | на нашем сайте, страница `/app` | на серверах Яндекса: загружается ZIP-архив в консоль разработчика |
| Сервер шаблона | обязателен (хаб SignalR, база) | не нужен: игрок, сохранения, лидерборды, реклама — через SDK Яндекса |
| Внешние ресурсы | любые | только файлы из архива; запросы к своему серверу — по списку хостов в консоли (CSP) |
| Проверка | модерации нет | модерация 3–5 рабочих дней по списку требований |

Поэтому игра лежит отдельно от сайта, в папке `YandexGame`, и в публикацию сайта не попадает.

## Структура

```
YandexGame/
├─ README.md                  — эта инструкция
├─ pack.ps1                   — упаковка игры в ZIP для консоли (с проверкой требований)
├─ html/                      — игра на HTML + CSS + jQuery + three.js; содержимое папки = корень архива
│  ├─ index.html              — подключение /sdk.js, библиотек и игры
│  ├─ css/game.css            — весь экран, без прокрутки и выделения текста
│  ├─ js/ysdk.js              — обёртка SDK (Ya): загрузка, пауза, реклама, сохранения, лидерборд, вход
│  ├─ js/lang.js              — локализация по языку из SDK (Lang)
│  ├─ js/game.js              — пример игры на three.js: всё, что проверяет модерация
│  └─ lib/                    — jQuery и three.js (r186, MIT) — внешние CDN запрещены, всё в архиве
├─ dev/
│  └─ sdk-mock.js             — заглушка SDK для локальной проверки (в архив не попадает)
└─ unity/Assets/              — для игры на Unity WebGL: копируется в Assets проекта Unity
   ├─ WebGLTemplates/YandexGames/index.html   — WebGL-шаблон: SDK, весь экран, мост JS ↔ C#
   ├─ Plugins/WebGL/YandexSDK.jslib            — вызовы SDK из C#
   └─ Scripts/YandexGames/YandexSDK.cs         — API для игры: YandexSDK.GameReady(), ShowRewarded(...), Save(...) и т.д.
```

Картинки, звуки и модели игры кладите в `html/` (например `html/img`, `html/sounds`, `html/models`) и подключайте относительными путями.

## Игра на HTML + jQuery + three.js

Игра обращается к Яндексу только через обёртку `Ya` (`js/ysdk.js`). Что уже сделано в примере и что сохранить в своей игре:

| Что | Где | Требование |
|---|---|---|
| `Ya.ready()` — когда всё загружено и можно играть | конец `game.js` | 1.19.2 |
| `Ya.gameplayStart()` / `Ya.gameplayStop()` — начало/конец уровня, меню, пауза | `startRound`, `endRound`, кнопка паузы | GameplayAPI |
| Пауза и звук при рекламе, сворачивании, покупке — `Ya.onPause` / `Ya.onResume` | `game.js`, раздел «Пауза» | 1.3, 4.7 |
| Язык — только из SDK: `Lang.init(Ya.lang)`, тексты через `data-t` | `lang.js` | 2.14 |
| Прогресс сохраняется сразу: `Ya.save({...})`, загрузка `await Ya.load()` | `endRound` | 1.9 |
| Полноэкранная реклама — только после действия игрока (между уровнями) | `startRound` | правила рекламы |
| Реклама за награду: кнопка прямо говорит про ролик, награда — бонус | `#bonusBtn` | 4.5.1, 4.5.2 |
| Нет прокрутки, выделения текста, меню по долгому нажатию | `game.css`, `contextmenu` | 1.6.1.8, 1.6.2.7, 1.10.2 |
| Весь экран на телефоне, поворот экрана | `resize()` в `game.js`, `viewport` | 1.6.1.1, 1.10 |

Своя игра пишется на месте примера: замените сцену и логику в `game.js`, тексты — в словаре `lang.js`. Лидерборд: создайте его в консоли и впишите техническое имя в константу `LEADERBOARD`.

## Проверка на своём компьютере

Игру с three.js нельзя открыть двойным щелчком по `index.html`: браузер не загружает ES-модули с диска. Есть три способа:

1. **Через сайт шаблона (быстро, без Node.js).** Запустите `_TemplateWeb` в режиме разработки (как обычно из Visual Studio) и откройте `http://localhost:<порт>/yagame/`. Сайт отдаёт игру из `YandexGame/html` и заглушку SDK `dev/sdk-mock.js` по адресу `/sdk.js` (только в Development). Заглушка показывает экран вместо рекламы, хранит сохранения в localStorage, ставит паузу при сворачивании вкладки и пишет вызовы SDK в консоль браузера. Язык: `/yagame/?lang=en`.
2. **Официальный локальный сервер Яндекса** (нужен Node.js): `npx @yandex-games/sdk-dev-proxy -p YandexGame/html --dev-mode=true` — откроет игру на `http://localhost:8080` с моками SDK. С ID черновика из консоли: `npx @yandex-games/sdk-dev-proxy -p YandexGame/html --app-id=<ID>` — игра откроется внутри страницы Яндекс Игр.
3. **Черновик в консоли** — после загрузки архива. Для отладки добавьте к адресу игры `?debug-mode=16`: в левом нижнем углу появится индикатор SDK (`IT` — SDK инициализирован правильно).

## Игра на Unity WebGL

1. Скопируйте содержимое `YandexGame/unity/Assets` в папку `Assets` проекта Unity.
2. **File → Build Profiles (Build Settings)** → платформа **Web (WebGL)** → Switch Platform.
3. **Player Settings → Resolution and Presentation → WebGL Template → YandexGames**.
4. **Player Settings → Publishing Settings:**
   - **Compression Format — Gzip** (или Brotli: архив меньше, сборка дольше);
   - **Decompression Fallback — включить.** Распаковку берёт на себя загрузчик Unity, и игра запускается независимо от заголовков сервера. Без этой галочки на части хостингов сборка не стартует;
   - **Data Caching** — по желанию (кэш в браузере ускоряет повторный запуск).
5. В игре вызывайте только `YandexSDK` (объект на сцену добавлять не нужно, он создаётся сам):

```csharp
void Start()
{
    string lang = YandexSDK.Lang;                       // язык интерфейса — только из SDK
    YandexSDK.Load(json =>                              // загрузка прогресса (пустая строка — сохранения нет)
    {
        if (json != "") progress = JsonUtility.FromJson<Progress>(json);
        YandexSDK.GameReady();                          // всё загружено, можно играть
    });
}

void StartLevel()  { YandexSDK.GameplayStart(); }
void FinishLevel() { YandexSDK.GameplayStop(); YandexSDK.Save(JsonUtility.ToJson(progress)); }
void NextLevel()   { YandexSDK.ShowFullscreen(shown => LoadNextLevel()); }      // реклама между уровнями
void Bonus()       { YandexSDK.ShowRewarded(ok => { if (ok) coins += 100; }); } // награда только если досмотрел
```

   На паузе от платформы (реклама, свёрнутая вкладка) `YandexSDK` сам ставит `Time.timeScale = 0` и `AudioListener.pause = true`, а потом возвращает как было. Если нужно что-то ещё — подпишитесь на `YandexSDK.Paused` / `YandexSDK.Resumed`. В редакторе Unity SDK нет: реклама пропускается, награда выдаётся сразу, сохранения — в PlayerPrefs.
6. **Build** → в папке сборки будут `index.html` и `Build/`. Упаковка: `.\pack.ps1 -Source <папка сборки> -Name mygame`.

Нужны покупки, отзывы, ярлык на рабочий стол и прочее — можно вместо этого моста поставить официально рекомендуемый Яндексом бесплатный плагин **Plugin Your Games 2.0** (https://max-games.ru/plugin-yg/doc/): он делает то же самое и больше, но тяжелее.

## Упаковка

```powershell
cd YandexGame
.\pack.ps1                                   # HTML-игра из папки html
.\pack.ps1 -Source D:\MyGame\Build -Name mygame   # сборка Unity
```

Архив появится в `YandexGame/dist`. Скрипт проверяет требования консоли: `index.html` в корне, размер до сжатия не больше 100 МБ, в именах файлов нет пробелов и кириллицы, в html и css нет ссылок на чужие адреса. Архив собирается с `/` в путях: стандартный `Compress-Archive` в Windows PowerShell 5.1 пишет `\`, и на сервере файлы не находятся.

## Публикация в Яндекс Играх

1. **Консоль разработчика:** https://games.yandex.ru/console/ — вход с Яндекс ID. Для монетизации (реклама, покупки) нужны документы: самозанятый, ИП или юрлицо. Проверка документов — около 3 рабочих дней.
2. **«Добавить игру»** — создаётся черновик.
3. **Загрузите архив** из `dist`.
4. **Заполните поля:** название, иконка, обложка, жанр/категории, описание, скриншоты (отдельно для десктопа и мобильных), видео, языки. Описание и промо-материалы — на каждый язык, на котором заявлена игра. Размеры и форматы картинок консоль показывает прямо в форме загрузки.
5. **По желанию:** страны распространения и хосты для запросов к своему серверу (CSP). Хосты — только `https`/`wss`, без путей, портов и IP-адресов; основная часть игры всё равно должна быть в архиве. Если игра ходит на сервер шаблона, при обрыве связи она должна сообщить об ошибке и дать повторить.
6. **Проверьте черновик** в консоли (`?debug-mode=16`): загрузка, реклама, пауза при сворачивании, сохранение после перезагрузки страницы, телефон в обеих ориентациях.
7. **Отправьте на модерацию** — 3–5 рабочих дней. Новый аккаунт может держать на модерации одну заявку, дальше — до двух.

## Частые причины отказа на модерации

- `LoadingAPI.ready()` не вызван или вызван, пока на экране ещё загрузка (1.19.2).
- Звук играет после сворачивания вкладки или во время рекламы (1.3, 4.7).
- Язык выбирается вручную, а не берётся из SDK; нет перевода на заявленный язык (2.14).
- Прогресс теряется после перезагрузки страницы (1.9).
- Прокрутка страницы, выделение текста, меню браузера по долгому нажатию (1.10.2, 1.6.1.8, 1.6.2.7).
- Полноэкранная реклама посреди игрового процесса; кнопка награды не говорит, что будет ролик (4.5.1).
- Ссылки на внешние сайты, сторы, соцсети (8.4.2); остатки разработки — «demo», «test» в интерфейсе (1.15).
- Пробелы или кириллица в именах файлов, архив больше 100 МБ (1.21, 1.22).
